# Image Splicing Detection Using Deep Learning

A deep learning-based image forensics project focused on detecting image manipulation and splicing using the CASIA 2.0 dataset.

## Overview

Image splicing is a type of digital image forgery in which a region from one image is copied and inserted into another image. Such manipulations can alter the original meaning and authenticity of an image.

This project explores a deep learning-based approach to image splicing detection using the **CASIA 2.0 Image Tampering Detection Evaluation Database**. The implementation and experiments are carried out using Kaggle Notebooks.

## Objectives

* Explore image splicing detection using deep learning.
* Work with authentic and tampered images from the CASIA 2.0 dataset.
* Develop a model to identify manipulated image content.
* Study the challenges of digital image forensics.
* Evaluate model performance using appropriate metrics, as supported by the implementation.

## Dataset

### CASIA 2.0

The CASIA 2.0 dataset is used for image tampering and forgery detection research. It contains authentic and tampered images, including manipulated images created using techniques such as splicing.

**Dataset details:**

* **Dataset:** CASIA Image Tampering Detection Evaluation Database, Version 2.0
* **Domain:** Digital image forensics
* **Image types:** Authentic and tampered images
* **Project use:** Image splicing detection and model experimentation

The dataset is used in accordance with its applicable access and usage conditions. The dataset files are not included in this repository.
